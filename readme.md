# 📚 공부 습관 대시보드 (Study Habits Dashboard)

파이썬을 처음 배우는 비전공자 학생들을 위한 Streamlit 기반의 웹 앱 프로젝트입니다. `study.csv` 데이터셋을 활용해 학생들이 공부 시간과 스마트폰 사용량이 점수에 미치는 영향을 쉽게 시각화하고 탐색할 수 있습니다.

---

## 🚀 주요 기능
- **데이터 요약 지표 (`st.metric`)**: 전체 학생 수, 평균 점수, 평균 공부시간을 한 줄에 깔끔하게 보여줍니다.
- **동적 필터링 (`st.slider`)**: 슬라이더로 최소 공부시간을 조절하여 조건에 맞는 학생들만 실시간으로 필터링합니다.
- **기본 시각화 (`streamlit chart`)**: 
  - 공부시간과 점수 간의 관계를 보여주는 **산점도 (Scatter Chart)**
  - 학생별 점수를 비교하는 **막대 그래프 (Bar Chart)**

---

## 🛠️ 설치 및 실행 방법

### 1. 필수 라이브러리 설치
터미널(명령 프롬프트)에 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. 파일 준비
- `app.py` (Streamlit 메인 코드)
- `study.csv` (학생 데이터 파일, 열: `학생ID`, `공부시간`, `스마트폰`, `점수`)
위 두 파일과 위에서 생성한 설정 파일들이 **동일한 폴더(디렉토리)**에 위치해야 합니다.

### 3. 앱 실행
터미널에서 아래 명령어를 실행합니다.
```bash
streamlit run app.py
```
실행 후 웹 브라우저가 자동으로 열리며 대시보드가 나타납니다!
